# 项目技术
- 后端语言：php
- 无需安装数据库，直接用SQLite，本地文件
- 页面样式：Bootstrap5
- 界面交互：ES6（fecth、Dom操作、Sortable排序）
- 无需apache/nginx，直接 php -S localhost:8000，启动服务
- Vibe Coding：第一次尝试 VS Code自带的Copilot，prompt.txt是提示词记录，api.php全部交给了AI，只测试了bug，没有看AI写的代码！其它基本古法编程+deepseek网页版，局部优化，辅助开发

# 部署
1. 去PHP官网下载windows安装包，解压，配置全局环境变量;
1. php.ini, extension=pdo_sqlite, 加载sqlite包;
1. 可选：php.ini error_log, 查看访问日志，日志文件会生成在项目目录下！
1. 将【PHP-DanTool.zip】解压，最好和PHP放在一块，防止误删;
1. 初始化数据库：打开CMD，cd到项目目录，输入：php database_init.php
1. 将项目目录里的【TJ排单工具.bat】发送到【桌面快捷方式】
1. 双击着桌面上的【TJ排单工具.bat】启动程序，在浏览器上输入: localhost:8000



# 使用说明
- 电商平台打单页面，复制产品编码（3E3E网格式），在主页搜索框里搜，eg：Q496冰雪丝提花蝴蝶睡裙，如果产品存在直接排单，如果产品不存在，填写产品信息，图片在打单页面缩略图邮件另存为，地址3E网复制；
- 拖动 厂家名称前面的【三】排序，按照自己的拿货路线走；
- 拖动 商品图片排序，将类似的放一块，挨着拿货；
- 拖动 到右下角的垃圾桶可以删除（厂家或者单个商品）
- 如果要修改厂家名称或者地址或者产品信息或者排单，可以双击图片或者搜索框搜索产品编码
- 右上角【打印预览】按钮，可以查看，今天需要拿货的单子（根据A4纸排版）
- 右上角【A4打印】，调用打印机（eg：惠普 HP Tank 580）
- 线下工具：A4纸单子、A4纸大小的夹板、带绳子的笔栓在夹板上

# 项目需求背景介绍
- 坐标：湖州织里童装城（其它类似：南通家纺城）
- 使用对象：使用3E3E网站的产品图片，需要每天去门店档口拿货发货的众多电商Seller，当网店出单后，需要去工厂门店档口拿货发货！
---
最近几年电商平台流量越来越分散，单品起爆款越来越难，为了店铺整体销量，很多小商家选择矩阵玩法（大量铺货），以前1个店铺10个产品，现在10个店铺，每个店铺100个产品！这样就出现一个拿货问题：去厂家A拿1件，去厂家B拿2件，去厂家C拿1件，去厂家D拿5件，.....，可以需要去几十上百家，拿货的人根本不熟悉档口地址，经常绕来绕去！因为订单分散，厂家太多，操作起来太混乱，用拿货小票容易丢，用手机信息太多密密麻麻，联系厂家留货，1件2件的还不如自己直接去拿！于是就有了这些需求：
- 拿货单上最好有图片，避免拿错货；
- 拿货单上可以用笔简单打勾，记录；
- 拿货单上显示厂家地址，按某个路线排好厂家顺序，一家一家按顺序去拿货；
- 厂家的产品货架位置通常有某种规律，同一个厂家拿货单上的产品能有顺序；
- 厂家改名或搬家后，信息可以修改
- 需要简化排单工作，减少重复性操作，有历史记录的厂家，今天只需要填写今天的订单，地址图片等信息不用重新设置；
